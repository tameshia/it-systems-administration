# IT Systems Administration Labs

A hands-on portfolio documenting my work with Windows administration, Linux, networking, system troubleshooting, and IT support fundamentals.

## About This Repository

I'm an Information Technology graduate with a concentration in Systems & Cybersecurity. This repository documents practical labs and technical exercises as I continue developing skills for IT support and systems administration roles.

Each project will include its objective, tools, procedures, troubleshooting observations, and lessons learned.

## Technical Focus

- Windows operating systems and administration
- System startup, recovery, and troubleshooting
- Windows command-line tools
- Linux fundamentals and administration
- Networking and connectivity troubleshooting
- Security configuration and access management

## Projects

### [Windows Management Part II: Devices, Storage, Automation, and Local Accounts](windows-management-part-ii/README.md)

**Windows 11 | Device Manager | Disk Management | Task Scheduler | Local Users and Groups**

Managed a virtual DVD-ROM, created a 97 MB NTFS simple volume and a 194 MB NTFS spanned volume with dynamic disks, tested and disabled a logon-triggered Command Prompt task, and verified LabUser01 membership in Windows-Lab-Users. Includes nine screenshots, evidence limits, troubleshooting guidance, security lessons, and official references.

### [Windows DiskPart Management: GPT Partitioning and NTFS Formatting](windows-diskpart-management/README.md)

**Windows 11 | Hyper-V | DiskPart | GPT | NTFS**

Verified a disposable virtual disk, cleaned and converted it to GPT, created and formatted a primary partition, and validated the assigned E: volume. Includes 13 screenshots, wrong-VM troubleshooting, an apartment-building teaching analogy, and notes distinguishing unallocated disk space from free volume space. `clean all` is reference material only; no `exit` screenshot is available.

### [Windows Local Security Policy: User Rights and Security Auditing](windows-local-security-policy/README.md)

**Windows 10 | Local Security Policy | User Rights | Event Viewer**

Configured and tested local security controls in a training VM, including user rights, interactive logon messaging, and file-system auditing. Reviewed Security events **4663**, **4647**, **4634**, and **4625**, documenting confirmed observations and an unconfirmed logon-session correlation. Includes 15 screenshot files covering configuration, policy tests, and security-event investigation.

### [Windows Command Prompt: File Management, Networking, and System Diagnostics](windows-command-prompt/README.md)

**Windows | Command Prompt | netstat | ipconfig | SFC**

Used the command line to create, copy, verify, and remove files and directories, troubleshoot a deletion error, inspect network activity, and start a system-file scan. Includes nine screenshots showing file operations, network diagnostics, and the start of a system file scan.

### [Windows Registry Editor: Backup, Modification, and Restoration](windows-registry-editor/README.md)

**Windows Server 2022 | Registry Editor | winver.exe | Notepad**

Backed up a Registry key, modified and verified the `RegisteredOwner` value, restored the original setting, and examined the contents of a `.reg` file. Includes screenshots of the original and modified owner values and Registry file structure.

### [Windows Startup Troubleshooting and Recovery](windows-startup-recovery/README.md)

**Windows 11 | Hyper-V | WinRE | BCDEdit**

Investigated Windows startup settings, intentionally simulated a boot failure in a virtual machine, and successfully restored normal startup. Includes screenshots, troubleshooting observations, and lessons learned.
