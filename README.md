# IT Systems Administration Labs

A hands-on portfolio documenting my work with Windows administration, Linux, networking, system troubleshooting, and IT support fundamentals.

## About This Repository

I'm an Information Technology graduate with a concentration in Systems & Cybersecurity. This repository documents practical labs and technical exercises as I continue developing skills for IT support and systems administration roles.

Each project will include its objective, tools, procedures, troubleshooting observations, and lessons learned.

## Technical Focus

- Windows operating systems and administration
- System startup, recovery, and troubleshooting
- Windows command-line tools
- Linux fundamentals and administration
- Networking and connectivity troubleshooting
- Security configuration and access management

## Projects

### [Windows Command Prompt: File Management, Networking, and System Diagnostics](windows-command-prompt/README.md)

**Windows | Command Prompt | netstat | ipconfig | SFC**

Used the command line to create, copy, verify, and remove files and directories, troubleshoot a deletion error, inspect network activity, and start a system-file scan. Screenshots will be added to the case study.

### [Windows Registry Editor: Backup, Modification, and Restoration](windows-registry-editor/README.md)

**Windows Server 2022 | Registry Editor | winver.exe | Notepad**

Backed up a Registry key, modified and verified the `RegisteredOwner` value, restored the original setting, and examined the contents of a `.reg` file. Screenshots will be added to the case study.

### [Windows Startup Troubleshooting and Recovery](windows-startup-recovery/README.md)

**Windows 11 | Hyper-V | WinRE | BCDEdit**

Investigated Windows startup settings, intentionally simulated a boot failure in a virtual machine, and successfully restored normal startup. Includes screenshots, troubleshooting observations, and lessons learned.
